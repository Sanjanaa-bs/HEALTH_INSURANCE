# Quarantined Evaluation Artifacts

The JSON files in this directory were generated during preliminary test runs that contained simulated embeddings (Python `hash()` instead of real MiniLM), rule-based LLM simulations, or synthetic multi-policy/hospital claims.

In compliance with the project's non-negotiable scientific integrity rules, these files have been quarantined. All evaluations reported in the camera-ready manuscript must be produced from reproducible, unsimulated scripts run on real data with seed tracking and file hashes.
